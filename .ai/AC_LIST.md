# AC_LIST — ITER-0014

## Goal

- 打开网页文件时窗口还要能操作。失败只留在阅读区，按钮不跟着消失。

## In Scope

- 看网页时顶栏和返回按钮留着。自动隐藏不再把它们收掉。
- 网页放在不跑脚本、也碰不到外层窗口的隔离框里。页面正文要等隔离属性确认还在，才放进去。
- 隔离放不上时，阅读区只显示「这个网页没法安全打开」，页面不再挂上。
- 文件读失败时，仍显示已有的失败原因，阅读区不出现网页隔离框。

## Out of Scope

- 不改网页里面的排版，也不让网页脚本跑起来。
- 白底页面，或脚本被挡住后没有画出来，不算打开失败，不改成提示。
- 不改 Markdown、纯文本、代码、图片、PDF、Office、压缩包和影音的打开方式。
- 不收口当前里程碑，不提交版本记录。

## Acceptance Checklist

- [ ] AC1: 自动隐藏开着、顶栏本应收起时，网页仍保持顶栏可见。返回按钮在。顶栏没有套上收起后点不到的样式。
- [ ] AC2: 网页隔离框的隔离属性（sandbox）是空字符串。页面正文在确认这个属性仍是空字符串之后才放进去。确认失败时，阅读区只显示「这个网页没法安全打开」，隔离框不留在页面上。外层仍按网页看待，顶栏仍按 AC1 留着。
- [ ] AC3: 网页的切换文案仍是「渲染 / 原文」。同样条件下 Markdown 的顶栏会收起，切换文案仍是「阅读 / 原文」。
- [ ] AC4: 打开结果已经是失败时，阅读区显示原来的失败原因，不出现网页隔离框。以「文件超过 2MB，这一段不整份读入」为例。

## Verification Method

- AC1: 渲染阅读框，种类是网页，自动隐藏已把顶栏关掉。看顶栏标记仍是打开，并能找到标题为「返回 Esc」的按钮。
- AC2: 渲染隔离框，看 sandbox 是空字符串，正文在框里。再模拟写入 sandbox 被丢掉，看提示出现，框不在。提示换在网页查看器内部，外层种类仍是网页。
- AC3: 同一组阅读框渲染。网页按钮文案是「渲染 / 原文」。Markdown 在顶栏关掉时标记为收起，按钮文案是「阅读 / 原文」。
- AC4: 打开文件的测试里，读入被拒绝并带上这句原因时，当前结果是失败，原因就是这句，不是网页正文。
