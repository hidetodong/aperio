# 一句话

打开网页文件时，页面把阅读区铺满，顶栏又会自己藏起来，窗口看起来像白屏，返回也点不到。这一轮让按钮留在窗口上。页面放不进隔离框，或者文件读失败时，只在阅读区给提示。

# Goal

- 打开网页文件不能把整个窗口打挂。失败之后，窗口还要能操作。

# Current Understanding

- 网页画在一个铺满阅读区的内嵌框里。鼠标移动到不了外层，顶栏按自动隐藏收起后，返回按钮既看不见也点不到。窗口就剩一块白。
- 已确认：打开网页不能把整个窗口打成白屏，窗口上的按钮不能因此消失。
- 已确认：打开失败时要有兜底提示，失败之后窗口还要能操作。
- 这台 Mac 的网页视图里，内嵌框带上空的隔离属性时，页里的脚本碰不到外层窗口。属性被拿掉时，脚本能改掉外层。
- 本轮采用的做法：网页仍放在这个隔离框里。看网页时顶栏不收。隔离放不上，就拿掉页面，阅读区只留一句提示。页面只是白底，或者脚本被挡住后没有画出来，仍算打开成功。

# Constraints

- 壳仍是 Tauri 2。网页解析留在前端，不进 Rust。
- 不让网页脚本跑起来，也不让它打开外层窗口。
- 文件读失败继续用现有的失败原因，不另起一套文案。
- 里程碑先不收口。这一轮不提交版本记录。工作区里本来就有未提交的改动，这一轮不把它们打成一次提交。

# Impact Scope

- 会动网页内嵌框、顶栏在网页时是否收起，以及隔离失败时阅读区的提示。
- 不动 Markdown、纯文本、代码、图片、PDF、Office、压缩包和影音的打开方式。
- 不改网页里面的排版。

# Project Type / Active Profiles

- 本地 Mac 阅读器。界面是 TypeScript 和 React。
- 没有启用领域画像，只按通用流程做。

# Open Questions

- 无。白底页面算打开成功，这一点按上面的做法定，不再等确认。
