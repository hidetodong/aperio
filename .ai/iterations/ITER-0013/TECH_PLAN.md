# TECH_PLAN — ITER-0013

方案状态: pass

## Design Decisions

### Goal

- 支撑已冻结的 AC1 到 AC6。纯文本改成阅读排版，代码上色和扩展名归类保持现状。

### Files / Modules to Change

- `src/formats/text/render.ts`：新增纯文本分段函数。只负责把文本切成段落，不碰 Markdown 和代码上色。
- `src/formats/text/TextView.tsx`：纯文本分支从一整块等宽原文改成文章段落。代码、Markdown、网页分支不改。
- `src/App.css`：纯文本的阅读栏规则从 `pre` 改到 `article`。补上无衬线字体和换行。专注模式那条底色规则留着。
- `src/formats/text/TextView.test.tsx`：补纯文本段落、代码行号和上色。
- `src/formats/route.test.ts`：补一条认不出的扩展名仍是 unknown、文本模式仍是纯文本。路由实现不改。
- `src/shell/ViewerFrame.test.tsx`：补纯文本没有「阅读 / 原文」和「渲染 / 原文」。工具条逻辑不改。

### Interface / Contract

- 分段函数收一段字符串，返回段落数组。连续空行（空行或只有空格、制表符的行）只当分隔，不进入段落文字。
- 段落内部不删首尾空白，所以原有缩进还在。
- 读文件时 Windows 换行 `\r\n` 先看成 `\n`，段落里不留下回车符。可见的字不变。
- 纯文本用 React 文本节点渲染，不把原文当 HTML 塞进去。
- 语言名单、`highlightCode`、打开路径和家族判断都不改签名。

### State / Boundary

- 不新增开关。纯文本没有原文模式。
- 不写磁盘。文本视图只吃已经读进来的字符串。
- 压缩包里的纯文本走同一块文本视图，会一起变成段落。压缩包的列表和解压不改。
- 图片、PDF、Office、影音、网页隔离框、Markdown 文章样式、代码颜色都不进这轮。
- 没有启用专项规则，只按通用流程。

### 取舍

- 采用：按空行切成段落，放进 `article` 里的 `p`。字体用已有的无衬线字体变量 `--font-sans`。字号继续用阅读字号变量 `--read-size`。长行用 `pre-wrap` 换行，再加 `overflow-wrap: break-word`，避免一长串不换行。段间距沿用文章段落现有的 `16px 0 0`，第一段顶距仍是 0。
- 放弃：只给现在的 `pre` 换字体。空行仍是一行行距，对不上文章段落那档 16px 空隙。
- 放弃：按每个换行都切段。单行换行要留在同一段里，否则会把原文的行改成另一套段落。
- 放弃：自动缩进或重写内容。

### Plan Admission

- AC 覆盖：AC1、AC2 由分段函数、文本视图和样式规则一起覆盖。AC3 不改上色实现，用 TypeScript 渲染测试和现有语言名单测试守住。AC4 不改 Markdown、网页和工具条，用现有测试加上纯文本没有切换按钮的测试守住。AC5 不改路由，补 log 这条断言。AC6 不改专注模式规则，用样式表读取守住。
- 假设：文章段落的空隙现在就是 `margin: 16px 0 0`。验收说的「同一档」就指这档，不另造一个数。
- 假设：纯文本的滚动容器已经带 `data-kind="plain"`。样式沿用这个钩子，不新造状态。
- 失败：空文件或只有空行时渲染空文章，不造出假段落。分段不抛错。
- 影响面：直接打开的纯文本，以及压缩包里同样走文本视图的纯文本，外观会变。能打开的种类不变。
- 验证盲区：自动测试看得到结构和样式规则，看不到系统窗口里字体是否顺眼，也看不到专注模式底色在真窗口里的样子。
- 准入结论：没有必须修改项。2026-10-28 用户确认。审查方式是 user-ack。

## Failure Paths

- 空字符串，或只有空行：渲染空的文章容器，不插入占位文字。
- 段内有缩进或连续空格：原样留在段落文字里。
- 只有单个换行：仍是一段，换行留在段内，靠样式换行。
- 原文里有尖括号或脚本字样：当文字显示，不当网页执行。
- 压缩包内的纯文本：跟着同一视图变成段落。打不开或列表不对，不在这条失败路径里处理。

## Test Strategy

- 分段和渲染：传入「甲\n\n乙」，得到两段，文字分别是甲和乙。再传入带缩进、带单个换行的文本，核对没有被改写。
- 样式表：纯文本文章使用 `--font-sans` 和 `--read-size`，长行是 `pre-wrap`。段落空隙规则仍是文章那条 `16px 0 0`。专注模式对 `data-kind="plain"` 的底色规则还在。
- 代码：渲染一段 TypeScript，看到行号和关键字上色。语言名单测试仍覆盖 js、jsx、mjs、cjs、ts、tsx、json、py、go、rs、sql、yml、yaml、css、sh、bash、zsh，并确认 rb 不是代码。
- 回归：现有 Markdown 文章测试和网页隔离框测试照跑。纯文本的工具条测试看不到「阅读」「原文」「渲染」。
- 路由：log 的家族是 unknown，文本模式是 plain。pdf、png、docx、zip、mp4 的原有断言照跑。
- 不在这轮把系统窗口当验收证据。窗口观感记在验证盲区。
