# AC_LIST — ITER-0010

## Goal

- 第一批图片能直接打开并看到图。M4V 能播。MKV 和 AVI 用安装包里的播放组件播，原文件不改。白色圆钮上的播放和暂停图标看得见。

## In Scope

- 放行 BMP、ICO、AVIF、JPEG XL、TIFF（`.tif` 和 `.tiff`），窗口直接显示，不转换。
- 放行 M4V，交给现有播放器，不先做临时文件。
- MKV 和 AVI 经安装包内的 FFmpeg 播放。能换包装就换包装，编码本身播不了才重编码。临时文件只为播放。
- 构建时下载这一份 Apple 芯片程序，仓库里不提交二进制。
- 这些新图片和新视频成功打开后进最近打开。PDF 仍不进。
- 播放和暂停图标在白色圆钮上可见。

## Out of Scope

- PSD、相机原始文件、WMV、旧版 Office、tar 和 gz。
- 不改已经能看的格式怎么打开，除非新扩展名走进了同一条打开路径。
- 不编辑，不提供另存为别的格式，不分享，不交给别的应用。
- 不改界面布局。播放键只改看不见的颜色。
- 不公证，不自动更新，不把安装包发给别人。
- 不把 Homebrew 的 FFmpeg 打进去。

## Acceptance Checklist

- [ ] AC1: BMP、ICO、AVIF、JPEG XL、TIFF 按图片打开，不经过转换。TIFF 同时认 `.tif` 和 `.tiff`。
- [ ] AC2: M4V 按现有视频播放，不先做临时文件。MP4、MOV、MP3 仍走原来的路径。
- [ ] AC3: MKV 和 AVI 播放时原文件内容不变。编码能播就换包装，不能播才重编码。临时文件不写在原文件旁边。
- [ ] AC4: 构建时取得一份允许随应用分发的 Apple 芯片 FFmpeg，安装包带上它。仓库不提交这份二进制。缺少它时说明播放组件没装好，不说成文件坏了。
- [ ] AC5: 新的图片和视频成功打开后进最近打开。成功打开的 PDF 仍不进。
- [ ] AC6: 播放和暂停图标在白色圆钮上是深色，能看见。
- [ ] AC7: PSD、相机原始文件、WMV、旧版 Office、tar 和 gz 仍然打不开，并沿用现在的说明。

## Verification Method

- AC1: 路由测试确认这些扩展名算图片，打开测试确认地址指向原文件，不调用解码。
- AC2: 路由和打开测试确认 M4V 算影音，且不调用播放准备。
- AC3: 纯函数测试区分换包装和重编码。有播放组件时，用短样片准备临时文件，并核对原文件字节没变。
- AC4: 下载脚本核对压缩包校验和。仓库忽略规则不含这份二进制。缺少程序时返回「播放组件没装好」。
- AC5: 最近打开测试覆盖新图片，以及准备后的 MKV 仍按原路径记入。PDF 用例保持不记入。
- AC6: 样式测试确认白色圆钮自己的深色规则压过按钮继承。
- AC7: 现有拒绝用例仍通过，新扩展名不误伤这些拒绝。
