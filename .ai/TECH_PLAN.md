## Design Decisions

- 目标只支撑 AC1 到 AC7。不提前做 PDF、Office、压缩包和影音。
- 壳用 Tauri 2，界面用 TypeScript、React、Vite。系统网页视图由壳带上，不把 Chrome 打进包。被放弃的做法是 Electron，因为它自带一整套浏览器，和“占内存小”对着干。
- 文件按扩展名归到家族。加载器里只有 image 和 text 两个动态导入。名单里关掉的家族直接返回不支持，导入函数不会被调用。被放弃的做法是启动时把所有查看器引进主包。
- 图片走本地资源地址显示，不把整张图读成内存里的 base64。HEIC 先由 Rust 调 sips 写成临时 png，再交给页面。被放弃的做法是在 Rust 里引一套 HEIC 解码库，违背“Rust 只做薄壳”。
- 文本由 Rust 按 UTF-8 读取，上限 2MB。Markdown 用轻量解析后再消毒。HTML 放进 sandbox 为空的内嵌框架，不给脚本权限。代码高亮只注册约定的语言。
- 最近列表的排序、去重、20 条上限放在可单测的纯函数里。Rust 只把结果写到应用数据目录里的一个 JSON 文件。
- 窗口状态同一时间只留当前这一份文件。换文件时丢掉上一份的内容和临时地址。
- 界面用系统字体，不做视觉定稿。仓库不提交字体文件。
- 没有启用技术画像。这一段按通用质量门禁做，不套别的框架细则。
- 写入范围只限 `/Users/cyborgno2/Documents/research/emerge`。

### 文件与模块

- `src/`：窗口、打开流程、启用名单、两个按需加载的查看器。
- `src-tauri/`：读文本、记最近列表、调 sips。不写格式解析。
- 测试放在对应纯函数旁边，外加一条 Rust 解码测试。

### 接口

- 打开一个路径，返回三种结果之一：图片地址、文本内容、不支持或失败原因。
- 最近列表项是路径、文件名、打开时间。写入函数只接受已经排好的列表。
- HEIC 解码只接受扩展名为 heic 或 heif 的现有文件，成功时返回临时 png 路径。

### 边界

- 前端负责显示和名单。Rust 负责本机文件和系统解码。
- 不在这一段创建 PDF、Office、压缩包、影音模块，避免它们被打进包。
- 资源协议要能读用户选中的本地文件。Markdown 和 HTML 都不再执行脚本，用来抵消“页面能读本地文件”这件事的风险。

### Plan Admission

- AC Coverage：AC1 由打开流程和窗口状态覆盖。AC2 由最近列表纯函数和数据目录读写覆盖。AC3 由扩展名归类和 sips 命令覆盖。AC4 由 Markdown 消毒、HTML 框架和高亮选择覆盖。AC5 由名单和加载器覆盖。AC6 由状态替换和 2MB 拒绝覆盖。AC7 由构建产物和依赖检查覆盖。
- Assumptions：这台 Mac 有 sips，Tauri 2 能在本机编过。验证方式是真的跑解码测试和构建。
- Alternatives / Trade-offs：Electron 放弃，因为内存。Rust 里做全部解析放弃，因为壳要薄。启动时加载全部查看器放弃，因为和按需加载相反。HTML 跑脚本放弃，因为这是阅读器。
- Failure Modes：文件不存在、路径是目录、文本不是 UTF-8、文本超过 2MB、sips 失败、拖进来的是关掉的格式。这些都返回说得清的原因，并清掉当前内容。sips 的参数用数组传递，不经过外壳字符串拼接。
- Impact / Scope Challenge：仓库是空的，没有旧模块可伤。更小的做法是先不做 HEIC，但 HEIC 已经在这一段的确认范围里，不能砍。PDF 不塞进来。
- Verification Blind Spots：拖放手感和窗口真实观感，自动化只能覆盖状态，覆盖不了手。空闲内存和冷启动受系统网页视图下限影响，数字要实测，测不到就记待人，不许估一个数写通过。
- Verdict：pass。验收都能落到可执行的检查，没有必须先停下来的设计缺陷。

## Failure Paths

- 文件不存在或是目录：提示找不到，当前内容清空。
- 文本不是 UTF-8，或超过 2MB：提示原因，不把半截二进制塞进页面。
- HEIC 解码失败：只这一张失败，JPG 等其他图片仍走资源地址。
- 名单里关掉的格式：提示这一段没开，不加载模块。
- sips 不存在：HEIC 失败并说明缺系统命令。

## Test Strategy

- 纯函数用 Vitest。最近列表、归类、消毒、高亮、换文件状态都在这里。
- HEIC 用 Cargo 测试加一条真实 sips 往返。非 heic 路径必须被拒绝。
- 构建后读 Vite 的产物清单，确认查看器不在主包里，且没有 PDF 块。
- 依赖和仓库文件做一次检索：没有 electron，没有提交的字体。
- 图形界面能起来时，用样例文件打开一次，并记录启动时间和空闲内存。起不来就记待人。
